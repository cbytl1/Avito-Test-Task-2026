# Avito Тестовое Задание 2026

Веб-приложение для продавцов, позволяющее управлять объявлениями и улучшать их с помощью нейросетей (LLM).

## 🚀 Быстрый запуск (Docker)

Для одновременного запуска фронтенда и бэкенда одной командой:

1.  Убедитесь, что **Docker Desktop** запущен.
2.  В корневой директории проекта выполните:
    ```bash
    docker compose up --build
    ```
3.  Приложение будет доступно по адресу: [http://localhost:5173](https://www.google.com/search?q=http://localhost:5173)
4.  Бэкенд API будет доступен по адресу: [http://localhost:8000](https://www.google.com/search?q=http://localhost:8000)

## 🛠 Технические изменения

В ходе реализации были внесены следующие правки в предоставленный бэкенд:

1.  **CORS Policy:** Добавлена поддержка CORS (через `@fastify/cors` / `middie`), чтобы разрешить запросы с фронтенда (`localhost:5173`). Реализована обработка `OPTIONS` запросов для корректной работы метода `PUT`.
2.  **API Data Schema:** В методе `GET /items` (список объявлений) в объекты массива `items` добавлено поле `id`. Это необходимо для корректной работы роутинга и перехода на страницу конкретного объявления.
3.  **Искусственная задержка:** Сохранена задержка ответов сервера (700-1000мс) для демонстрации состояний загрузки (Skeletons) в интерфейсе.
